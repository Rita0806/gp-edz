广平经济开发区服务平台 · Railway 部署说明（微信可直开版）
================================================================

目标：把本应用部署到 Railway，实现
  1) 微信内直接打开（不被 workbuddy.link 网关拦截）
  2) 能输入账号密码登录（后端 server.js 已内置）
  3) 转发给好友显示「标题+简介+封面图」小程序式卡片（OG 元信息已加）

账号（与代码内置一致，可改 server.js 的 ACCOUNTS）：

  后台   / 123123  （角色 admin）

---------------------------------------------------------------
方式一：纯网页操作（推荐，不用碰命令行）
---------------------------------------------------------------
① 注册 GitHub：打开 https://github.com → 点 Sign up，按提示注册（免费）。

② 新建仓库：登录后点右上角 ＋ → New repository
   - Repository name 随便填，如 gp-edz
   - 选 Public（或 Private 都行，Railway 授权后可访问）
   - 不要勾 Add a README → 点 Create repository

③ 上传代码：进入刚建好的空仓库
   - 点绿色「Code」→ 点「Upload files / 上传文件」
   - 把你下载的 gp_edz_deploy.zip 解压后的 deploy_pkg 整个文件夹
     直接拖进网页（GitHub 网页支持拖文件夹，会保留 assets/、data/ 子目录）
   - 翻到最下面点「Commit changes」提交

④ 注册 Railway：打开 https://railway.app → 点 Start / Login
   - 建议选「Continue with GitHub」一键登录并授权

⑤ 从 GitHub 部署：Railway 控制台点「New Project」
   - 选「Deploy from GitHub repo」
   - 授权后选你刚建的 gp-edz 仓库
   - Railway 会自动识别 package.json 的 "start": "node server.js" 并部署
   - 等 1~2 分钟，状态变 ✅ Deployed

⑥ 拿到地址：项目页顶部会显示域名，形如
   https://gp-edz-xxxx.up.railway.app
   点开 → 用「后台 / 123123」登录，验证功能正常。

⑦ 微信测试：把该 railway.app 链接发到微信文件传输助手 / 好友，
   在微信里直接点开。若提示在浏览器打开，见下方「⑧ 绑自有域名」。

---------------------------------------------------------------
方式二：Railway CLI（适合愿意装软件，一步上传）
---------------------------------------------------------------
① 本机装 Node.js：https://nodejs.org 下载 LTS 版，一路下一步装好。
② 装 Railway 命令行（需命令行）：
     npm install -g @railway/cli
③ 登录：railway login   （会自动弹出浏览器授权）
④ 进入解压后的 deploy_pkg 目录，部署：
     railway init        （选空项目或新建）
     railway up          （打包上传并部署）
⑤ 完成后 Railway 控制台给出域名，同上测试。

---------------------------------------------------------------
⑧ 绑自有域名（彻底避免微信拦截 + 转发卡片生效）
---------------------------------------------------------------
railway.app 子域名绝大多数情况微信能开，但为 100% 稳妥（及让转发卡片
正确显示封面图），建议绑定你自己的域名：
  1) 买一个域名（阿里云/腾讯云/Cloudflare 均可，几元~几十元/年）
  2) Railway 项目 → Settings → Domains → 填你的域名（如 gp.你的域名.com）
  3) 按提示到域名 DNS 加一条 CNAME 指向 Railway 给的地址
  4) 十几分钟后生效，微信打开 + 转发卡片即为小程序式效果

---------------------------------------------------------------
数据持久化（重要）
---------------------------------------------------------------
代码已支持 Railway 持久卷：在 Railway 项目 → Volumes → Add Volume，
挂载路径填 /data。代码会自动把数据写到该卷，重启/重新部署都不丢。
（不挂卷也能跑，但容器重启会回到部署时的初始数据。）

招商动态每 10 分钟从参考站自动同步；县领导意见在本地填写的优先级更高。
若参考站临时账号被删，会回退到静态 invest_data.js，不影响主功能。

---------------------------------------------------------------
常见排查
---------------------------------------------------------------
- 打不开：Railway 控制台看 Deploy Logs 有无报错；确认 start 是 node server.js。
- 502/空白：多半是子域名被微信拦，按 ⑧ 绑自有域名即可。
- 登录失败：确认 server.js 内 ACCOUNTS 的账号密码，与前端一致。
